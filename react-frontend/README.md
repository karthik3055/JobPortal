# Job Portal React Frontend

React frontend for the Job Portal Spring Boot REST API.

## Stack

- React
- Vite
- JavaScript
- CSS

## Features

- User registration
- User login
- Skill-based job matching
- Job applications
- Application listing
- Responsive interface

## Run

Install dependencies:

npm install

Start the frontend:

npm run dev

The frontend expects the Spring Boot backend at:

http://localhost:8080/api
